Supprimer votre compte Scridle

Application : Scridle (Android, com.monent.scridle) · Éditeur : Monent

Vous pouvez demander la suppression de votre compte Scridle et de toutes les données qui y sont liées, à tout moment et gratuitement. Vous n'avez pas besoin d'avoir encore le jeu installé.

Comment faire

  • 1

    Envoyez un e-mail à monentcie@gmail.com avec pour objet « Suppression de mon compte Scridle ».

  • 2

    Envoyez-le depuis l'adresse e-mail utilisée pour votre compte et indiquez votre pseudo dans le jeu. Cela nous permet de vérifier que la demande vient bien de vous.

✉️ Écrire la demande

⏱️

Nous traitons la demande sous 30 jours au maximum et vous confirmons la suppression par e-mail.

Données supprimées

  • Votre compte : adresse e-mail, mot de passe et identifiant de compte ;
  • votre sauvegarde dans le cloud (progression, équipements, succès) ;
  • votre pseudo et votre place dans le classement ;
  • votre jeton de notification ;
  • vos défis contre d'autres joueurs.

Données conservées

Aucune donnée de votre compte n'est conservée après la suppression, sauf si la loi nous y oblige.

La partie enregistrée sur votre téléphone n'est pas concernée : elle reste sur l'appareil jusqu'à ce que vous désinstalliez le jeu ou effaciez ses données (Paramètres Android → Applications → Scridle → Stockage → Effacer les données).

Les données publicitaires sont gérées par Google AdMob. Vous pouvez réinitialiser ou supprimer votre identifiant publicitaire dans les paramètres Android (Google → Annonces).

Supprimer seulement certaines données

Vous pouvez aussi demander à supprimer seulement une partie de vos données (par exemple votre pseudo du classement) sans supprimer votre compte : précisez-le dans votre e-mail.

Pour en savoir plus sur les données collectées, consultez la politique de confidentialité.
